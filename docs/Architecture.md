# Architecture

Techno Store is a console-based e-commerce application organized using a layered architecture within a single project.

The project separates responsibilities into different folders to keep the code organized and reduce coupling between components.

## Project Structure

```text
Techno_Store
│
├── Application
│   ├── DTOs
│   └── Mapping
│
├── Domain
│
├── Interfaces
│
├── Migrations
│
├── Services
│
├── UI
│
├── Program.cs
├── appsettings.json
└── ...
